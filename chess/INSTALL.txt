Morse Chess Club for alltherex.com/chess
========================================

Plesk on this domain cannot run the Node Morse Chess app. This folder is the
PHP club that plays the same game: accounts, Morse coins, standings, challenges
by username, MorseBot, and a timed or untimed board.

The Vercel site keeps its own Postgres database. Those logins are not in MySQL.
Create a database in Plesk and enter it on the first page. The settings are
saved in morse-private/config.php, one folder above this site, so a Git pull
does not wipe them.

If that folder cannot be written, set these in Plesk instead:

  MORSE_DB_HOST=localhost
  MORSE_DB_NAME=the database name
  MORSE_DB_USER=the database user
  MORSE_DB_PASS=the database password

PHP 8.1 or newer. Give the database user every privilege on that database.
The host is usually localhost.
