# Map data

Country outlines in `countries.json` come from **Natural Earth** Admin 0
Countries at 1:110m (cultural vectors). Natural Earth data is in the public
domain.

> Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

Source: https://www.naturalearthdata.com/
Vector repository used to obtain the GeoJSON:
https://github.com/nvkelso/natural-earth-vector
(file: `geojson/ne_110m_admin_0_countries.geojson`)

Coordinates were rounded and lightly simplified for the game. No country
shapes were invented.
